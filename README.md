# Superstore Sales Analysis using SQL

## About the project
Analyzed 9,800 retail order records using SQL to find top customers,
best-selling categories, and yearly sales trends.

## Dataset
Superstore Sales Dataset (Kaggle): 9,800 rows, 4,922 orders.

## Tools
SQLite, DB Browser for SQLite

## SQL concepts used
SELECT, WHERE, ORDER BY, LIMIT, GROUP BY, HAVING, COUNT, SUM, AVG,
CASE, subquery, JOIN

## Key findings
- Total sales were about 2.26 million across 4,922 orders.
- Technology is the top category with 827,455.87 in sales, followed by Furniture (728,658.58) and Office Supplies (705,422.33).
- Sean Miller is the top customer with 25,043.05 in total purchases.
- Yearly sales dipped slightly in 2016 (459,436.01), then grew every year, reaching 722,052.02 in 2018, about 50% higher than 2015.
